# 우주 레이싱

three.js로 만드는 학급용 3D 레이싱 게임 (진행 중).

## 실행
정적 사이트라서 Vercel에 올리면 바로 동작합니다.
내 컴퓨터에서 볼 때는 폴더에서 `npx serve .` 또는 `python -m http.server`로 연 뒤 브라우저에서 엽니다.
(index.html을 더블클릭하면 모듈 보안 제한 때문에 열리지 않습니다.)

- 그래픽 낮추기: 설정 → 그래픽 품질, 또는 주소 뒤에 `?q=light` (선명하게는 `?q=sharp`)
- 터치 버튼 강제로 켜기: 주소 뒤에 `?touch=1` (태블릿에서는 저절로 켜짐)

## 진행 단계
- [x] 1-A 달 기지 서킷 코스·배경, 코스 보기 카메라
- [x] 1-B 차량 조작, 추적 카메라, 랩 계측 (연습 주행)
- [x] 2-A AI 차량 5대, 순위, 결과 (그랑프리)
- [x] 2-B 부스터 1·2단, 우주과학 퀴즈, 바퀴 모드·피트, 먼지 구간, 태양풍
- [x] 3-A 머신 4종·색·드라이버 이름, 난이도, 설정(품질·바퀴 수·카메라·자동 가속), 사용방법
- [x] 3-B 기록실(최고 기록·최근 경주 50개), 태블릿 터치 조작, 느린 컴퓨터 안내
- [x] 코스 추가(화성 협곡, 유로파 얼음), 효과음·배경음(Web Audio 합성), 태블릿 기울여서 조종, 입문 주행 도우미

## 폴더
- `js/course/` 코스 정의(courses.js: 코스별 지형·하늘·후반 날씨), 주행선, 지형, 도로, 기지 시설, 하늘
- `js/audio/sound.js` 효과음·엔진 소리·배경음 (소리 파일 없이 합성)
- `js/core/` 렌더러·조명, 카메라, 키보드 입력, 기울기 센서(tilt.js)
- `js/vehicle/` 레이서 모양(machines.js에 머신 목록)과 주행 물리
- `js/race/` 랩 계측, 경기 진행 · `js/ui/` 경기 화면 · `js/fx/` 먼지 효과
- `js/quiz/questions.js` 부스터 퀴즈 문항 (여기만 고치면 문항이 바뀜)
- `js/store.js` 기록 저장 (지금은 브라우저)
- three.js r170은 jsDelivr CDN에서 불러옵니다 (index.html의 importmap)
